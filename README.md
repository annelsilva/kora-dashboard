# Kora — Dashboard de Gestão Financeira

Acesse a aplicação online: https://annelsilva.github.io/kora-dashboard/

## Sobre o Projeto
Interface web para controle de fluxo de caixa, análise de receitas e despesas por categoria e exportação de relatórios financeiros. Desenvolvido com foco em tipografia tabular, hierarquia visual e responsividade.

## Funcionalidades
- **Indicadores consolidados:** Cálculo automático de saldo líquido, total de entradas, total de saídas e margem financeira.
- **Visualização de dados:** Gráfico de barras comparando o fluxo mensal e gráfico de rosca com distribuição percentual por categoria.
- **Filtros combinados:** Busca textual em tempo real, filtro por mês, categoria e tipo de movimentação.
- **Persistência local:** Armazenamento automático dos lançamentos no navegador via `localStorage`.
- **Exportação:** Geração de planilha `.csv` compatível com Excel respeitando os filtros ativos na tela.
- **Temas:** Alternância entre modo claro e modo escuro com adaptação dinâmica dos gráficos.

## Tecnologias
- HTML5 semântico
- CSS3 (Variáveis CSS, Grid e Flexbox)
- JavaScript (ES6+)
- Chart.js
